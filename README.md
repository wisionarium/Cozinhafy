# Cozinhafy 🍳

Sistema moderno e interativo de autoatendimento para restaurantes, comanda digital para clientes e tela KDS (Kitchen Display System) em tempo real para a cozinha.

## ✨ Recursos

- 📱 **Interface do Cliente (Autoatendimento)**: Cardápio interativo, montagem de pratos executivos/PF personalizáveis, carrinho dinâmico e envio direto para a cozinha com animações.
- 🍳 **Tela da Cozinha (KDS / Notinhas)**: Pedidos organizados no estilo notinha de prancheta, lista ordenada de ingredientes, alertas sonoros e status de preparo.
- 📊 **Painel Administrativo**: Gestão de cardápio, criação e reordenação de categorias, controle de disponibilidade e métricas de vendas.
- ⚡ **Tempo Real**: Suporte a sincronização instantânea multi-dispositivos via Supabase Realtime e fallback local via BroadcastChannel e localStorage.
- 🚀 **Deploy Fácil**: Otimizado para Vite e hospedagem instantânea na Vercel.

## 🛠️ Tecnologias

- Vanilla JavaScript (ES Modules)
- CSS3 Moderno (Design responsivo, tema notinha, zero dependência de frameworks pesados)
- Vite
- Supabase (PostgreSQL em Tempo Real)
